# Как сделать скриншоты для отчёта (ПР №4, вариант 2)

В архиве:
- `student-diary/` – готовый проект (README.md, .gitignore, diary.py)
- `init_repo.ps1` (Windows) и `init_repo.sh` (Linux/macOS) – создают локальный репозиторий с 2 коммитами (замена ПР №3)
- `task4/features.md` – файл для Задания 4

Если у вас уже есть репозиторий из ПР №3, можно использовать его, а `student-diary/` не трогать.

## 0. Подготовка (один раз)
1. Установите Git: https://git-scm.com
2. Настройте имя и почту:
   git config --global user.name "Ваше Имя"
   git config --global user.email "ваша_почта@example.com"
3. Распакуйте архив и запустите скрипт:
   - Windows (PowerShell): `powershell -ExecutionPolicy Bypass -File .\init_repo.ps1`
   - Linux/macOS: `bash init_repo.sh`
   В конце должны появиться 2 коммита (`git log --oneline`).

## Задание 1 → Рисунок 1
1. github.com → New repository → название `student-diary`, Public.
2. НЕ ставьте галочки Add a README, .gitignore, license.
3. Create repository.
Скриншот: страница пустого репозитория с блоком «Quick setup» и HTTPS-адресом.

## Задание 2 → Рисунки 2 и 3
В терминале, в папке `student-diary`:
   git remote add origin https://github.com/ВАШ_ЛОГИН/student-diary.git
   git remote -v
   git branch -M main
   git push -u origin main
Скриншот 2: терминал с выводом `git remote -v` и `git push`.
Скриншот 3: обновлённая страница репозитория на GitHub (файлы и «2 Commits»).

## Задание 3 → Рисунок 4
1. На GitHub откройте README.md → значок карандаша → в конец добавьте:
   ## Технологии

   - Python 3
   - SQLite
   - Git и GitHub
2. Commit changes (сообщение по умолчанию `Update README.md`).
3. В терминале:
   git pull origin main
   cat README.md        (в PowerShell: type README.md)
Скриншот: вывод `git pull` и содержимое README.md в одном окне терминала.

## Задание 4 → Рисунки 5 и 6
1. Скопируйте `task4/features.md` в папку `student-diary`.
2. В терминале:
   git add features.md
   git commit -m "Add list of key features"
   git push
   git log --oneline
3. Скриншот 5: GitHub → вкладка «Commits» (должно быть 4 коммита).
4. Скриншот 6: главная страница репозитория со всеми файлами
   (.gitignore, README.md, diary.py, features.md).

## Советы
- Запрос логина при push: войдите через окно браузера (Git Credential Manager) или используйте Personal Access Token: GitHub → Settings → Developer settings → Tokens.
- Если push отклонён из-за расхождения историй – репозиторий на GitHub создан с README. Создайте его заново пустым.
- В README.md в строке «Студент группы ____» впишите свою группу до первого push (или оставьте как есть).
- Проверить приложение: `python diary.py`.
