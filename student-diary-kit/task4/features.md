# Ключевые функции приложения «Онлайн-дневник студента»

1. **Электронный дневник** – запись домашних заданий по предметам со сроками сдачи.
2. **Расписание занятий** – просмотр расписания на день и на неделю.
3. **Учёт оценок** – ввод оценок и автоматический расчёт среднего балла по каждому предмету.
4. **Напоминания** – уведомления о приближающихся сроках сдачи заданий.
5. **Заметки к занятиям** – краткие записи по темам пройденных уроков.
