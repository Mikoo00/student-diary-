# Student Diary

Учебный проект: онлайн-дневник студента с расписанием занятий.

Консольное приложение позволяет вести расписание на неделю,
записывать домашние задания со сроками сдачи и учитывать оценки
по предметам.

## Запуск

```
python diary.py
```
